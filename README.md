# Advanced ML Bootcamp

My coursework repository for the **Advanced ML Bootcamp**. Each week's work lives in its own
folder and is submitted through a reviewed pull request.

## Repository structure

```
advanced-ml/
├── README.md            # this file
├── .github/
│   └── pull_request_template.md
├── week01/
│   ├── notes.md         # summary of lessons learnt
│   └── ...              # homework / assignments / implementations
├── week02/
│   └── notes.md
└── ...
```

## How I work each week

1. Create a branch from `development` (or `main`) named `week<NN>-<topic>`
   (e.g. `week01-introduction-to-ml`).
2. Add a `weekNN/` folder containing a `notes.md` plus any assignments or implementations.
3. Commit with clear messages and push the branch.
4. Raise a pull request into `development` / `main` and add the instructor as a reviewer.
5. Address feedback, then merge once approved.
